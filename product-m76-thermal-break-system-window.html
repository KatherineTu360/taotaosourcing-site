Product overview

M76 supports inward tilt-turn and outward-opening window layouts with a 1.8 mm main-profile wall thickness. Buyers can configure glass, handles, screens and colour around the project drawing, with performance values checked against the final size and test documentation.

  • 6063-T5 aluminum profile
  • 24 mm thermal-break reference
  • Inward tilt-turn or outward-opening configuration
  • External high-transparency or security mesh option
